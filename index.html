Clips Today Uploader

Clips Today Uploader is a personal tool that posts gaming highlight clips to my own TikTok account, @gta.clips.today.

It runs only on the owner's own computer. It is not offered to the public, and no one else can sign in to it or use it.

What it does

  • Prepares short vertical highlight clips from gaming streams.
  • Uses the TikTok Content Posting API to upload those clips to the owner's own TikTok account.
  • Reads basic info and view counts for the owner's own videos.
