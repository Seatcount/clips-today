Privacy Policy

Clips Today Uploader ("the app") is a personal tool that posts videos to its owner's own TikTok account, @gta.clips.today.

What the app uses

  • Only the TikTok account owner's own login token, which TikTok gives the app after the owner approves it.
  • The token is used only to post the owner's own videos and read basic info and view counts for those videos.

Where it is stored

The token is stored locally on the owner's own computer. It is not sent to any server run by the app, and it is never shared or sold.

Other people's data

The app collects no data from other users. It has no public sign-in, no accounts for others, no analytics, and no cookies.

Removing access

The owner can revoke the app's access at any time in TikTok settings, which makes the stored token stop working.
